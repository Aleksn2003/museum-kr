Инструкция администратора

Вход

Запустите проект командой docker compose up -d --build, откройте http://localhost:8080/admin.html и войдите с логином admin и паролем из ADMIN_PASSWORD в локальном файле .env. Не публикуйте этот файл и пароль. Кнопка «Выйти» удаляет токен из браузера; после истечения сессии войдите снова.

Материалы сайта

  • Раздел «Обзор» показывает количество материалов, статусы новостей и мероприятий, ближайшее опубликованное событие, текущий режим работы и последние изменения.
  • В разделах «Экспонаты», «Новости», «Мероприятия» и «Категории» можно создавать записи, изменять их, переводить на английский и удалять.
  • Кнопка «Изменить» открывает запись целиком, кнопка EN — только английские поля. Если перевода нет, сайт показывает русский текст.
  • Для новости и мероприятия выберите статус: «Черновик» доступен только в админке, «Опубликовано» показывается на сайте, «Скрыто» остаётся в админке, но убирается с публичных страниц и поиска.
  • Кнопка «Посмотреть» открывает предпросмотр записи до публикации. В редакторе страниц кнопка «Посмотреть страницу» открывает соответствующую публичную страницу.
  • Удаление новости или мероприятия скрывает запись. При удалении категории она отвязывается от экспонатов.
  • Изображения: JPEG, PNG, WebP или GIF, максимум 10 МБ на файл. Перед сохранением показывается предпросмотр; сервер проверяет содержимое файла. В галерее экспоната — до четырёх изображений.
  • В разделе «Тексты сайта» выберите страницу. Для главной и архитектуры используются безопасные отдельные поля: можно менять тексты и фотографии, не затрагивая оформление. Для остальных страниц редактор загрузит их исходное содержимое; сохранение заменяет содержимое выбранной страницы целиком.
  • Русская и английская версии страниц сохраняются отдельно. Если английский перевод ещё не создан, редактор покажет русскую версию — переведите её перед сохранением.
  • В разделе «Цены» задаются билеты для взрослых, студентов, пенсионеров и школьников, стоимость экскурсии и возраст бесплатного посещения. После сохранения значения обновляются на главной странице и в разделе «Посетителям».
  • «Медиатека» показывает загруженные изображения и места их использования. Кнопка «Выбрать из медиатеки» в полях изображения позволяет повторно использовать фотографию; для галереи можно выбрать несколько кадров.
  • Для экспоната задайте «Порядок отображения» (меньшее число показывается выше) и отметьте не более одного экспоната дня. Если отметка не задана, сайт выбирает случайный экспонат на текущий день.
  • «Расписание исключений» позволяет добавить закрытый день или рабочую дату с особым временем. Исключения применяются автоматически по времени Якутска и перекрывают недельное расписание.
  • «История изменений страниц» хранит предыдущую версию до каждого сохранения. Можно отменить последнее изменение выбранной страницы и языка; структура страницы восстанавливается целиком.
  • В «Настройках сайта» можно изменить русские и английские названия музея и филиала, загрузить логотип, задать рабочие дни и время открытия / закрытия. В автоматическом режиме статус в боковой панели переключается по этому расписанию. Для праздника или санитарного дня можно выбрать ручной статус.

Admin guide

Sign in

Run docker compose up -d --build, open http://localhost:8080/admin.html, and sign in as admin with the password configured as ADMIN_PASSWORD in your local .env file. Never publish that file or password. The Log out button removes the browser token; sign in again after the session expires.

Managing content

  • The Overview shows content totals, news and event statuses, the next published event, current opening status, and recent changes.
  • Exhibits, News, Events, and Categories support creating, editing, translating, and deleting records.
  • Edit opens a complete record; EN edits only its English fields. Missing translations fall back to Russian on the public site.
  • Choose a publication status for news and events: Draft is visible only in the admin panel, Published appears on the public site, and Hidden stays in the admin panel but is removed from public pages and search.
  • Preview opens a record before publication. The page editor's View page link opens the corresponding public page.
  • News and events are hidden when deleted. Deleting a category detaches it from related exhibits.
  • JPEG, PNG, WebP, and GIF images up to 10 MB are accepted. The panel previews them and the API checks the actual file type. Exhibit galleries support up to four images.
  • In Site Texts, select a page. The home and architecture pages use structured fields so their layout stays intact; the remaining pages use the full content editor.
  • Russian and English page versions are stored separately. If no English translation exists yet, the editor shows the Russian version; translate it before saving.
  • Prices controls adult, student, pensioner and school tickets, tour pricing, and the free admission age. Saved values appear on the home page and the Visitors page.
  • Media Library lists uploaded images and where each is used. Use the library picker beside image fields to reuse a photo; gallery pickers support multiple images.
  • Set an exhibit's display order (a smaller number appears first) and select at most one Exhibit of the Day. If none is selected, the site chooses one for the current day.
  • Schedule Exceptions adds closed dates or special opening hours. Exceptions are applied automatically in Yakutsk time and override the weekly schedule.
  • Page Change History stores the previous version before each save. You can undo the latest change for the selected page and language; the full page version is restored.
  • Site Settings lets you change the museum and branch names in Russian and English, upload a logo, and set working days and opening / closing times. In automatic mode, the sidebar status follows this schedule. You can set a manual status for public holidays and sanitation days.
